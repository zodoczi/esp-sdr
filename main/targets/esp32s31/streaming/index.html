Radio settings

Bandwidth: 0 follows the sample rate automatically; 13–54 MHz sets it manually. While streaming, use your SDR application's controls to keep its display in sync.

Signal quality & connection tips

Use the native high-speed USB port for samples. Only one transport can stream at a time. If another device shares the USB bus, try 16 MSa/s.

In manual gain mode, hardware DC calibration runs before reception starts. Hardware AGC selects gain automatically; the gain index applies in manual mode. SoapyESPSDR can also remove the residual DC. Reduce gain if strong signals clip. Automatic bandwidth reduces out-of-band noise. The analog filter has a 13 MHz minimum, so lower sample rates can still alias; use external filtering when needed.

Samples contain 8 bits per I and Q. Selecting CS16 or CF32 in the application changes the output format, not the ADC resolution. This firmware is for Soapy applications; use the separate burst target for the serial web viewer.
